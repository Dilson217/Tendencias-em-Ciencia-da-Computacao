## 1. Apresentação

O **StudyFlow — Gerenciador Inteligente de Tarefas Acadêmicas** é uma aplicação web desenvolvida como atividade prática da disciplina de Tendências em Ciência da Computação, utilizando a abordagem de Low Code / No Code, com foco em Vibecode.

O projeto tem como objetivo auxiliar estudantes na organização e no gerenciamento de suas tarefas acadêmicas, permitindo cadastrar atividades, definir prioridades, acompanhar prazos e visualizar o progresso dos estudos.

## 4. Ferramenta e Abordagem Utilizadas

- **Ferramenta:** Lovable.
- **Abordagem:** Low Code / No Code.
- **Metodologia explorada:** Vibecode.
- **Linguagens e tecnologias:** React, TypeScript, Vite e Tailwind CSS.

## 5. Funcionalidades Principais

- Cadastro de tarefas acadêmicas.
- Edição e exclusão de atividades.
- Definição de prioridades.
- Gerenciamento de status das tarefas.
- Pesquisa e filtros.
- Acompanhamento de prazos.
- Painel com indicadores de progresso.
- Armazenamento local das tarefas no navegador.

## 6. Objetivo da Atividade

Aplicar os conceitos de desenvolvimento Low Code / No Code por meio da criação de uma aplicação funcional, explorando o uso de ferramentas que permitem acelerar o desenvolvimento de software com apoio de inteligência artificial.

O projeto também possibilitou compreender as vantagens e limitações do Vibecode, destacando a importância da revisão do código, dos testes e da validação das funcionalidades implementadas.
